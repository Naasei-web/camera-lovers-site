# Camera Lovers Site

A simple photography-themed website built to practice and strengthen my frontend development skills using HTML, CSS, and JavaScript.

## Features

- Photography-themed design
- Responsive layout
- Navigation menu
- Photography resources and links
- Interactive elements using JavaScript
- Clean and simple user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

This project helped me improve my understanding of HTML structure, CSS styling and layouts, and basic JavaScript interactions.

I also practiced building a complete webpage from scratch and organizing the different parts of a frontend project.
